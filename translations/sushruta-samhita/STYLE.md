# 《妙闻集》藏译工程 · 子 agent 通用体例与术语指令

## 你的任务
把 Bhishagratna 1907 英译版《Suśruta Saṃhitā · Sūtrasthāna》中若干章，逐段译为藏文（乌金体、藏文字母），作为**机器初译稿**。所有输出都是初稿，须经藏医/译师人工审定，不必追求完美，但必须严守以下体例。

## 硬性体例（**必须**遵守，不得省略）

### 1. 章开头
每章第一段前加：
```
༄༅། །དེ་ནས་《章题梵/汉》ཞེས་བྱ་བའི་ལེའུ་བཤད་པར་བྱ་སྟེ།
```
即"今当宣说……品"。章题用梵文音写或工程文件已给的藏文拟译（见下方章题表）。

### 2. 章末
每章正文最后加：
```
ཞེས་བྱ་བ་《章题》ཞེས་བྱ་བའི་ལེའུ་སྟེ། 《章号》པའོ།། ། །
```

### 3. 段落格式
- Bhishagratna 英译的每一自然段 → 藏文一段，段前若英文原文标注了颂号 [n]，藏文段首保留 `【n】` 作为颂号占位。
- 英文中的诗节（Metrical texts）在藏文段末标 `（tshig gsum）` 或直接分行短句。
- 段与段之间空一行。

### 5. 音写规则（梵文→藏文）
- 长元音 ā ī ū → ཱ ཱི ཱུ
- ṛ → རྀ
- ai / au → ཻ / ཽ
- ṇ ṭ ḍ → ཎ ཊ ཌ
- ś → ཤ；ṣ → ཥ；s → ས
- 词末闭音节加 འ 或直接闭合
- 药物拉丁学名首见处保留：`藏文音写／梵文（Sanskrit）／拉丁学名（若英文原文可判定）`

### 6. 标注
- 无对应藏医术语的梵文病名/药名：保留梵文音写 + 首见处加脚注 `⟨脚注：梵 Xxx，义为……⟩`
- 有争议处加 `⟨审⟩`
- 剂量、marma 方位、罕见药物：`⟨待审：藏医验定⟩`

### 7. 不做的事
- 不加译者自己解释
- 不"意译丰富化"，逐段对应即可
- 不省略英文里的列表、数字、剂量
- 不用威利转写（Wylie），一律藏文字母

## 输出格式
输出一份纯文本（不用 markdown 语法，除章标题外），每章之间用 `--- 章 X 结束 ---` 分隔。章开头一行标 `[CH_XX] 章题梵/藏`。
