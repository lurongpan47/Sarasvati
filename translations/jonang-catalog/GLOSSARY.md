## 待复核项 (open questions)

1. 域摩传承早期的几位藏名人名（南喀沃色 / 色摩且瓦等）汉译是否统一采用学界通行拼法？目前采用 Pinyin 式音译，但《藏学辞典》等参考书可能用不同形式。
2. 多波巴 (Dolpopa) 的全名 Shes-rab rGyal-mtshan — 汉译界有 "喜饶坚赞"、"西饶坚赞"、"喜饶坚参" 多种，草稿采 "喜饶坚赞"。
3. 教派对内 (Jonangpa 内部) 的"遍知"头衔是尊称，与格鲁派、宁玛派"遍知"用法有否区别需复核。
4. 翻译中 ⟨བརྟག⟩ 标记指所有汉译整段为草稿，不是某个具体词。
5. **(10-17 推送线抽查)** p088 `དཀའ་བཞི་འཛིན་པ་བློ་ལྡན་བཟང་པོ` (dka' bzhi 'dzin pa blo ldan bzang po) → 稿作「四难论持者宝贤 (Kādrug Dzinpa Lodan Zangpo)」。**宝贤** = rin chen bzang po，此处应为「洛丹桑波」（义译「慧贤」）；「Kādrug」应为 *dka' bzhi*（四难）。未改稿；同类「X贤」义译人名请复核者全文核对（*bzang po* 前的词根）。
6. **(10-17)** `pages_tib/` 抽取丢失下加字（ླ / ྱ 等，见 README 第 5 条），人名音译凡经模型「还原」者皆应对照原书。
