Sarasvatī branch: **`pali`** — with cross-lingual anchor into **`chinese`** (T1 长阿含《游行经》 · T7 《大般涅槃经》) and **`tibetan`** (Kangyur ཡོངས་སུ་མྱ་ངན་ལས་འདས་པ།).

## Files

## Passages selected

1. **Attadīpā** — "Be lamps unto yourselves"（自灯明·法灯明） DN 16.2.26
2. **Ādittapariyāya** — the four great authorities（四大教法） DN 16.4.7
3. **Final exhortation** — "vayadhammā saṅkhārā"（诸行无常，当自精勤） DN 16.6.7
