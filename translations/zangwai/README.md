# zangwai · 藏外文献 Extracanonical Tibetan

**Tier 1 · Rank 2** — Pan's 2026-11-02 orphan-canon brief.

## Why Tier 1 Rank 2

The Tibetan canon has Kanjur (~1,100 texts) + Tenjur (~3,600 texts). Outside the canon is **much larger**: Nyingma rGyud-'bum (~300+ tantras in the 46-volume mTshams brag edition), Bön Kanjur (178 vols) and Bön Tenjur, and lineage masters' gSung-'bum (collected works, each master = 10–30 volumes). Many of these are:
- Single-lineage holdings
- Not yet digitally input beyond scanning
- Preserve material lost in sanskrit, chinese, or anywhere else

BDRC has scans for a large portion but full-text input lags scan preservation by decades.

## Sub-directories

- `nyingma-gyubum/` — rNying ma rGyud 'bum, Nyingma collected tantras
- `bon-kanjur/` — Bön Kanjur + Tenjur
- `gsung-bum/` — individual masters' collected works (highest-priority candidates: Jonang masters whose Jonang catalog we already worked on; Dolpopa, Tāranātha, etc.)

## License

- BDRC image scans: open-access with per-collection terms. Default: safe to link and quote; large mirror needs per-collection check.
- Tohoku Univ. Derge Tenjur/Kanjur IIIF database: scheduled public release spring 2026. Likely CC BY. Will cover canonical not extracanonical.
- Tibetan monastic reproductions post-1950: variable; check per-print.
- Pre-1950 blockprints: public domain in Tibet / India / most jurisdictions.
