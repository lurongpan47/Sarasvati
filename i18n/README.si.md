# Sarasvatī — සම්භාව්‍ය ග්‍රන්ථ සඳහා ගෝලීය විවෘත ලේඛනාගාරය

**Sarasvatī** (ටිබෙට්: དབྱངས་ཅན་མ། · සංස්කෘත: सरस्वती) යනු ලෝකයේ
සම්භාව්‍ය ග්‍රන්ථ ආරක්ෂා කිරීම සහ බහුභාෂා පරිවර්තනය සඳහා වූ ගෝලීය
විවෘත ලේඛනාගාරයකි.

## මෙය අවශ්‍ය වන්නේ ඇයි

සම්භාව්‍ය ග්‍රන්ථ මනුෂ්‍යත්වයේ පොදු උරුමයයි. ඒවා කතුහිමිකම් යටතේ
අගුළු දැමීම, යුද්ධයෙන් පිළිස්සීම, හෝ කැඩුණු සබැඳි නිසා නැති කිරීම
නොවිය යුතුය. Sarasvatī කරුණු තුනක් කරයි:

1. **පරිවර්තනය.** පොදු වසමේ මූලාශ්‍ර ග්‍රන්ථ සඳහා, තවමත් පරිවර්තනයක්
   නොමැති භාෂාවලට AI-සහායක යන්ත්‍ර-කෙටුම්පත් සකසමින්, විශේෂඥ මානව
   සමාලෝචනය සඳහා විවෘතව ආරාධනා කරමු.
2. **ලේඛනාගාරය.** සෑම කෘතියක්ම SHA-256 අඛණ්ඩතා දර්ශනයක් සමඟ අවම වශයෙන්
   ස්ථාන තුනක (GitHub, දේශීය, වලාකුළ) දර්පණ කරනු ලැබේ.
3. **නිකුත් කිරීම.** සියල්ල CC BY-SA 4.0 යටතේ ප්‍රකාශයට පත් කෙරේ. ව්‍යුත්පන්න
   කෘතිද විවෘතව පැවතිය යුතුය.
