# Sarasvatī — คลังเปิดระดับโลกสำหรับคัมภีร์คลาสสิก

**Sarasvatī** (ทิเบต: དབྱངས་ཅན་མ། · สันสกฤต: सरस्वती) คือคลังเปิด
ระดับโลกสำหรับการอนุรักษ์และการแปลข้ามภาษาของคัมภีร์คลาสสิกโลก

## เหตุใดจึงมีโครงการนี้

คัมภีร์คลาสสิกคือมรดกร่วมของมนุษยชาติ ไม่ควรถูกกักไว้ด้วยลิขสิทธิ์
ไม่ควรถูกเผาด้วยสงคราม และไม่ควรสูญหายเพราะลิงก์ที่เสียหาย
Sarasvatī ทำสามสิ่ง:

1. **แปล** สำหรับคัมภีร์ต้นฉบับที่อยู่ในสาธารณสมบัติ เราจัดทำร่าง
   จากเครื่องด้วยความช่วยเหลือของ AI สู่ภาษาที่ยังไม่มีคำแปล และเปิด
   รับการตรวจทานโดยผู้เชี่ยวชาญที่เป็นมนุษย์
2. **จัดเก็บ** เอกสารทุกชิ้นถูกทำสำเนากระจกอย่างน้อยสามแห่ง (GitHub,
   เครื่องท้องถิ่น, คลาวด์) พร้อมกับ manifest ความสมบูรณ์แบบ SHA-256
3. **เผยแพร่** ทุกอย่างเผยแพร่ภายใต้ CC BY-SA 4.0 งานสืบเนื่อง
   ต้องคงความเปิดไว้เช่นกัน

## แผนงาน (แปดสาย)

โครงสร้างระยะยาวของ Sarasvatī ยึดตามไทม์ไลน์การถ่ายทอดคัมภีร์
พุทธศาสนาของโลก: **India · Sanskrit manuscripts · Pāli · Southeast
Asian Theravāda · Silk Road · Chinese canon · Sinosphere · Tibetan**
แต่ละสายอาจมีหลายโครงการแปล โครงการที่ดำเนินการอยู่ในปัจจุบันอยู่ใต้
สาย **Tibetan** ได้แก่ การแปลบทที่เหลืออีก 140 บทของ Suśruta Saṃhitā
