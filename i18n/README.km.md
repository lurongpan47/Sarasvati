# Sarasvatī — បណ្ណសារបើកចំហជាសកលសម្រាប់គម្ពីរបុរាណ

**Sarasvatī** (ទីបេ៖ དབྱངས་ཅན་མ། · សំស្ក្រឹត៖ सरस्वती) គឺជាបណ្ណសារបើកចំហជាសកលសម្រាប់ការការពារ និងការបកប្រែឆ្លងភាសានៃគម្ពីរបុរាណរបស់ពិភពលោក។

## ហេតុអ្វីបានជាមានគម្រោងនេះ

អត្ថបទបុរាណគឺជាមរតកសាធារណៈរបស់មនុស្សជាតិ។ ពួកវាមិនគួរត្រូវបានចាក់សោនៅពីក្រោយសិទ្ធិអ្នកនិពន្ធ ដុតដោយសង្គ្រាម ឬបាត់បង់ដោយសារតំណភ្ជាប់ខូចនោះទេ។ Sarasvatī ធ្វើរឿងបីយ៉ាង៖

1. **បកប្រែ។** សម្រាប់អត្ថបទប្រភពដែលនៅក្នុងវិស័យសាធារណៈ យើងបង្កើតសេចក្តីព្រាងម៉ាស៊ីនដែលមានជំនួយពី AI ទៅជាភាសាដែលនៅតែខ្វះការបកប្រែ ហើយអញ្ជើញការត្រួតពិនិត្យដោយអ្នកជំនាញមនុស្សដោយបើកចំហ។
2. **រក្សាទុកជាបណ្ណសារ។** សម្ភារៈនីមួយៗត្រូវបានឆ្លុះនៅទីតាំងយ៉ាងហោចណាស់បីកន្លែង (GitHub, មូលដ្ឋាន, ពពក) ជាមួយនឹងសេចក្តីប្រកាសសុចរិតភាព SHA-256។
3. **ចេញផ្សាយ។** អ្វីៗទាំងអស់ត្រូវបានបោះពុម្ពក្រោមអាជ្ញាប័ណ្ណ CC BY-SA 4.0។ ស្នាដៃដេរីវេត្រូវតែនៅតែបើកចំហ។
