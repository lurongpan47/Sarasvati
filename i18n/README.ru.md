# Sarasvatī — глобальный открытый архив классических канонов

**Sarasvatī** (тибетский: དབྱངས་ཅན་མ། · санскрит: सरस्वती) — это глобальный
открытый архив для защиты и межъязыкового перевода классических канонов
мира.

## Зачем это существует

Классические тексты — общее наследие человечества. Они не должны быть
заперты за авторскими правами, сожжены войной или потеряны из-за
неработающих ссылок. Sarasvatī делает три вещи:

1. **Переводит.** Для исходных текстов, находящихся в общественном
   достоянии, мы создаём машинные черновики с помощью ИИ на языки, для
   которых ещё нет перевода, и открыто приглашаем экспертов к проверке.
2. **Архивирует.** Каждый артефакт зеркалируется как минимум в трёх местах
   (GitHub, локально, облако) с манифестами целостности SHA-256.
3. **Публикует.** Всё публикуется под лицензией CC BY-SA 4.0. Производные
   работы должны оставаться открытыми.

## Текущий выпуск

**v0.2.0** (2026-08-28):

- 📜 **Suśruta Saṃhitā · Sūtrasthāna** — все 46 глав переведены с
  Bhishagratna 1907 (английский, общественное достояние) на тибетский с
  помощью четырёхканального параллельного ИИ-конвейера. Ноль остаточных
  китайских иероглифов. Сомнительные места помечены ⟨བརྟག⟩ / ⟨བརྟག་དགོས།⟩
  для экспертной проверки.
- 📊 Структурированные данные хронологии — 80 событий канонической
  передачи в 8 буддийских традициях (india, sanskrit, pali, seasia,
  silkroad, chinese, sinosphere, tibetan) в форматах JSONL/CSV.
- 📋 План проекта, руководство по стилю, терминологический глоссарий и
  справочные материалы.

## Дорожная карта (восемь ветвей)

Долгосрочная структура Sarasvatī следует хронологии передачи мирового
буддийского канона: **Индия · Санскритские рукописи · Пали ·
Юго-Восточная Тхеравада · Шёлковый путь · Китайский канон · Синосфера ·
Тибетский**. Каждая ветвь может содержать несколько переводческих
проектов. Текущий активный проект находится в **тибетской** ветви:
продолжение оставшихся 140 глав Suśruta Saṃhitā.

## ⚠️ Отказ от ответственности

Все переводы здесь являются **машинными черновиками**, ожидающими
проверки человеческими экспертами. Не полагайтесь на них как на
авторитетные для медицинских, ритуальных или научных целей без
подтверждения квалифицированными специалистами.

## Как внести вклад

- Откройте issue с предложением текста, пересмотра главы или исправления
  терминологии.
- Сделайте форк, отредактируйте, отправьте PR. Все вклады принимаются под
  CC BY-SA 4.0.
- Запустите зеркало. Помогите сохранить архив.
