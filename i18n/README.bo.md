# Sarasvatī — འཛམ་གླིང་གི་གནའ་བོའི་གཞུང་རྙིང་གི་ཆེད་དུ་སྤྱི་ཡོངས་ཁ་ཕྱེ་བའི་ཉར་ཚགས་ཁང༌།

**Sarasvatī**（བོད་སྐད་དུ། དབྱངས་ཅན་མ། · ལེགས་སྦྱར་སྐད་དུ། सरस्वती）ནི།
འཛམ་གླིང་གི་གནའ་བོའི་གཞུང་རྙིང་རྣམས་སྲུང་སྐྱོབ་དང་སྐད་མང་བར་སྒྱུར་བའི་

## མ་འོངས་པའི་ལམ་སྟོན།（ཡལ་ག་བརྒྱད།）

Sarasvatī ཡི་ཡུན་རིང་གི་གྲུབ་ཚུལ་ནི། འཛམ་གླིང་སངས་རྒྱས་པའི་གཞུང་བརྒྱུད་
དུས་མཚམས་ལས་མ་འདས་ཏེ། **རྒྱ་གར། ལེགས་སྦྱར་གྱི་ཕྱག་བྲིས། པཱ་ལི།
ལྷོ་ཤར་ཨེ་ཤི་ཡའི་གནས་བརྟན་པ། དར་གོས་ལམ། རྒྱ་ནག་གི་གཞུང་། རྒྱ་ཡིག་རིག་གནས་ཁྱོན།
བོད།** ཞེས་པའོ། ཡལ་ག་རེ་རེ་ལ་སྒྱུར་བའི་ལས་གཞི་མང་པོ་གནས་ཐུབ། ད་ལྟ་འགྲོ་བཞིན་པའི་
ལས་གཞི་ནི། **བོད་** ཀྱི་ཡལ་གའི་འོག་ཏུ་ཡོད་དེ། Suśruta Saṃhitā ཡི་ལྷག་མའི་ལེའུ་ ༡༤༠
མུ་མཐུད་སྒྱུར་བའི་ལས་ཀ་ཡིན།
